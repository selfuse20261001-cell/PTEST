# 家用 KTV 使用說明（PiKaraoke 台灣中文歌版）

用一台電腦當 KTV 主機，接上電視播放；大家用手機掃 QR Code 就能點歌，不用裝 App。
歌曲從 YouTube 找伴唱版下載到電腦再播放，所以不會遇到「不允許嵌入播放」，也不需要 YouTube 金鑰。

本版以 [PiKaraoke](https://github.com/vicwomg/pikaraoke) 為基礎，針對台灣中文歌調整，差異請見文末。

## 一、需要準備

| 項目 | 說明 |
|---|---|
| 一台電腦 | Windows 10/11、macOS、Linux 或樹莓派 4 以上 |
| 電視 | 用 HDMI 接電腦；或用電視/電視盒的瀏覽器開播放畫面 |
| 網路 | 電腦和手機連**同一個 Wi-Fi**（不要用訪客網路） |
| 硬碟空間 | 每首歌約 20–50 MB |
| 麥克風 | 建議接硬體混音器或 K 歌擴大機，聲音才不會延遲 |

## 二、下載

在 GitHub 頁面按綠色的 **Code → Download ZIP**，解壓縮到任意資料夾（例如「文件\\KTV」）。

## 三、第一次啟動

### Windows

1. 雙擊 **`start.bat`**。
2. 第一次會自動安裝 uv、FFmpeg、Deno（需要幾分鐘），裝完會提示你**關掉視窗再雙擊一次**。
3. 第二次啟動會下載 Python 套件，接著自動用瀏覽器開出全螢幕的播放畫面。

> 出現藍色「Windows 已保護您的電腦」時，按「其他資訊 → 仍要執行」。

### macOS / Linux

在終端機進入資料夾，執行：

```sh
./start.sh
```

macOS 需要先有 [Homebrew](https://brew.sh)；Linux（Debian/Ubuntu/樹莓派）會用 apt 安裝 FFmpeg，可能會要求輸入密碼。

## 四、開始唱歌

1. 把電腦畫面接到電視，畫面上會顯示 **QR Code 和網址**（例如 `http://192.168.1.20:5555`）。
2. 第一次開播放畫面時，按一下畫面上的「確認」，瀏覽器才允許自動播放。
3. 大家用手機掃 QR Code，輸入自己的名字就能點歌。

### 手機上的功能

| 頁面 | 可以做什麼 |
|---|---|
| **首頁（正在播放）** | 暫停/播放、切歌、從頭重唱、升降 Key、調音量 |
| **點歌清單** | 看接下來的歌、插播到最前面、往上/往下移、移除 |
| **歌曲** | 搜尋已下載的歌，直接點歌 |
| **找新歌** | 搜尋 YouTube 伴唱版，按「點歌」會下載並排入清單；按「先存起來」只下載不排 |
| **演唱紀錄／排行榜** | 每晚自動記錄誰唱了什麼，看熱門歌曲和麥霸排行 |

### 找歌小技巧

- 打**中文歌名**時，會自動只找標題含「KTV」的影片，通常就是伴唱版。
- 找不到想要的版本，可以加上歌手名，例如「告白氣球 周杰倫」。
- 想找原唱 MV 或非伴唱版，勾選「包含非伴唱版本」。
- 也可以在「找新歌 → 進階」直接貼 YouTube 網址。
- 下載過的歌會留在電腦裡，下次點同一首就不用再下載。

## 五、常用設定（手機 → 設定）

| 設定 | 說明 |
|---|---|
| 歌庫 → **中文歌搜尋時附加的關鍵字** | 預設「KTV」，可改成「伴唱」或「卡拉OK」 |
| 管理員 → **設定密碼** | 設了之後，只有你能切歌、改歌名、關機；其他人只能點歌 |
| 伺服器設定 → **每人可點歌曲數上限** | 避免有人一次點太多 |
| 伺服器設定 → **啟用公平輪唱** | 大家輪流唱，不會被同一人連續霸佔 |
| 伺服器設定 → **自動整理 YouTube 標題** | 把「周杰倫【告白氣球】KTV 伴唱版」整理成「周杰倫 - 告白氣球」 |
| 伺服器設定 → **音量標準化** | 讓每首歌音量差不多 |
| 電視畫面設定 | 隱藏 QR Code、評分畫面、背景音樂等 |

## 六、常見問題

**手機掃 QR Code 連不上**

- 確認手機和電腦連同一個 Wi-Fi（不是 4G/5G、不是訪客網路）。
- Windows 請雙擊 **`fix-firewall.bat`**，在跳出的視窗按「是」，開放防火牆。
- 用手機內建的 Chrome / Safari 開，不要用 LINE 等 App 內建的瀏覽器。

**搜尋或下載突然失敗**
到「設定 → 更新 → 更新 yt-dlp」，YouTube 改版時通常更新就會好。

**想用電視盒或另一台電腦當播放畫面**
執行 `start.bat --headless`（macOS/Linux：`./start.sh --headless`），再用電視的瀏覽器開 `http://電腦IP:5555/splash`。

**歌曲存在哪裡？**
預設在使用者資料夾的 `pikaraoke-songs`。要換位置：`start.bat -d D:\KTV歌曲`。

**怎麼關掉？**
在手機「設定 → 結束 PiKaraoke」，或直接關掉黑色視窗。

**介面變成英文了**
「設定 → 語言設定」選「Chinese (Traditional)」，再重新啟動。

**更多啟動參數**
執行 `start.bat --help` 或 `./start.sh --help` 查看。

## 七、與原版 PiKaraoke 的差異

- 預設繁體中文介面，翻譯全部改成台灣 KTV 用語（點歌清單、歌庫、切歌、插播、升降 Key）。
- 中文歌搜尋改用「KTV」關鍵字，找到伴唱版的機率較高；關鍵字可在設定調整。
- 正確整理「歌手【歌名】KTV」這類台灣伴唱影片標題，並移除「伴唱」「官方MV」「高音質」等字詞。
- iTunes 歌名建議預設使用台灣區。

原版英文說明請見 [docs/README.md](docs/README.md)。
