# PiKaraoke 台灣中文歌版

這個分支以 [PiKaraoke](https://github.com/vicwomg/pikaraoke) 為基礎，針對在台灣唱中文歌做了調整。安裝與執行方式跟原版相同，請參考 [README.md](README.md)。

## 與原版的差異

- **預設繁體中文介面**：不論手機或電腦的瀏覽器語言為何，預設都顯示繁體中文。可在「設定 > 語言設定」改回其他語言。
- **台灣用語**：介面翻譯全面改為台灣 KTV 慣用說法，例如「點歌清單」、「歌庫」、「切歌」、「插播」、「升降 Key」。
- **中文歌搜尋找伴唱版**：搜尋字詞含中文時，YouTube 搜尋會要求標題含「KTV」，而不是英文的「karaoke」，台灣的伴唱影片大多這樣命名。關鍵字可在「設定 > 歌庫」改成「伴唱」或「卡拉OK」等。
- **正確整理台灣 KTV 影片標題**：「周杰倫【告白氣球】KTV 伴唱版」這類標題會整理成「周杰倫 - 告白氣球」，不再只剩歌手名；也會移除「伴唱」、「官方MV」、「高音質」等字詞。
- **iTunes 歌名建議預設台灣區**：批次改名時，iTunes 會用台灣商店的中文歌名與歌手名。

## 執行

```sh
uv run pikaraoke
```

用手機掃電視上的 QR Code 就能點歌。
